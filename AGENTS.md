# Klyx - agent guide

`CLAUDE.md` is the canonical, maintained project guide for every agent (Claude
Code, Codex, Copilot, Antigravity) and for humans: the product brief, the
non-goals and their recorded crossings, the locked tech stack, the
architecture, the milestone history, the design rules and the working style.
Read it before working in this repository.

This file used to be a separate copy, frozen on 2026-06-13, and it drifted: it
still said the non-goals were hard, `klyx serve` was planned, M5-c was next and
Argo never prunes - all overruled since. It is now a pointer so there is one
source of truth (retired 2026-10-04).
